Emberline — defend the last lantern through ten waves of night. A complete, original 2D canvas arena-defence game: move with WASD, aim with the mouse, hold click to shoot ember bolts, drop flash bombs with Space, and spend embers on upgrade cards between waves. Survive all ten waves and defeat the Gloom Herald to bring back the dawn.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080
```
